Paste values

Accepts one goal per line, for example 9: Industry, Innovation and Infrastructure   5, or 17 numbers separated by commas, spaces or newlines. Goals you leave out are set to zero.

How to use

  1. Set Number of subjects to how many you want to compare, from 1 to 6. A named column appears for each.
  2. Rename each column by typing over Subject 1, Subject 2 and so on. The name becomes the legend label.
  3. Score every goal from 0 to 5 in each column. The chart redraws as you type.
  4. Use Paste values to fill a whole column at once — pick the target column first, then paste and press Read values.
  5. Press Download PNG to save the chart for a report or course file.

What the 0–5 score means

The scale is relative, not absolute. If you are deriving scores from a project-by-project SDG matrix, the usual method is: count the projects marking each goal primary (P) and secondary (S), compute a weighted count as P + 0.5 × S, then normalise so the highest-scoring goal becomes 5 — round(5 × weighted ÷ max weighted). Because of that normalisation some goal always reaches 5. Two charts therefore compare shape, not magnitude.

Accepted paste formats

One goal per line, where the leading number is the goal and the last number on the line is the score:

1: No Poverty	0
2: Zero Hunger	1
3: Good Health and Well-being	4

Or 17 plain numbers separated by commas, spaces or newlines: 0, 1, 4, 4, 0, 1, 0, 2, 5, 3, 5, 1, 2, 0, 0, 0, 0. Any goal you leave out is set to 0.

Notes

  • Values outside 0–5 are clamped; decimals are rounded; blank cells count as 0.
  • Each subject gets its own colour and dash pattern, so the chart stays readable in greyscale print.
  • The axis is fixed at 0–5 rather than auto-scaling, so charts made at different times stay directly comparable.
  • Nothing is saved — values live in the page only. Download the PNG, or keep the numbers in your spreadsheet.
  • The page loads Chart.js from a CDN, so it needs an internet connection the first time it opens.
